# My Notes

My Notes to aplikacja na Androida do tworzenia, edytowania i usuwania notatek. Działa offline i zapisuje dane w prywatnej bazie SQLite na telefonie.

Lista pokazuje najpierw ostatnio zmienione notatki. Przycisk „Nowa notatka” otwiera edytor, a stuknięcie istniejącej notatki pozwala ją zmienić albo usunąć.

Interfejs jest napisany w Kotlinie i Jetpack Compose. Debugowe APK można zbudować poleceniem `./gradlew :app:assembleDebug` (`gradlew.bat` na Windows).
